# dsh-peak-status

[English](README.md) | 中文

![peak indicator 预览](assets/peak-indicator.png)

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web GUI 的高峰时段指示灯。在会话头部右上角显示一个融入界面的小胶囊，实时告诉你当前**北京时间**是否处于 DeepSeek API 的**高峰时段**，带秒级时钟、下一转折倒计时和价格提示。

## 高峰时段

DeepSeek 官方峰谷定价（2026-08-17 生效，2026-08-23 起周末调整）：

| 状态 | 时段（北京时间） | 价格 |
| :-- | :-- | :-- |
| 🔴 **高峰** | 工作日 09:00–12:00 和 14:00–18:00 | 高峰价（= 空闲 ×2） |
| 🟢 **空闲** | 其余时间——包括周六、周日全天 | 高峰的一半 |

周末（周六、周日）全天按谷价计费，不设高峰时段。

按 DeepSeek 峰谷时间说明，能有高峰窗口的只有"既非周六周日、也非法定节假日"的普通工作日：

| 日期 | 状态（北京时间） |
| :-- | :-- |
| 中国法定节假日 | 全天按空闲时段计费，与周末一致 |
| 调休上班的周末 | 同样全天按空闲时段计费（调休不改计费，只影响标签） |

所以 10 月 1 日显示 🟢 **国庆节**、调休的周六显示 🟢 **调休上班 · 谷价**，两者都不进高峰。

## 功能

- 状态圆点——**红 = 高峰，绿 = 空闲**，外加实时北京时钟（`HH:MM:SS`，时区 `Asia/Shanghai`，与本机时区无关）
- 倒计时：高峰时显示 `剩 3h 54m · 价格 ×2`，空闲时显示 `距高峰 3h 54m · 半价`
- 节假日感知：法定节假日直接显示节日名（如 `国庆节`），并倒计时到假期结束后的第一个高峰窗口；调休上班的周末显示全天谷价并标注该日
- 点击胶囊展开详情卡：高峰窗口、下一转折（含 `HH:MM:SS` 倒计时）、当前阶段进度条
- 全部使用 Web UI 原生 `--dsw-alias-*` 主题变量，与界面完全融合，没有悬浮贴片
- 持久挂载：重启 dsh web 后依然存在
- 经济模式：每个对话独立的绿叶开关，高峰自动暂停该对话的模型请求，空闲（半价）期自动恢复，挂起时显示绿叶休眠条

## 安装

```sh
dsh plugin --profile web add dsh-peak-status
```

也可以直接从 GitHub 安装：

```sh
dsh plugin --profile web add github:xiaoyi-xx/dsh-peak-status
```

然后重启 `dsh web`（或刷新页面），胶囊会出现在会话头部右上角。

## 使用

胶囊每秒自动更新。点击展开/收起详情卡，悬停有快捷提示。高峰/空闲状态严格按上面官方时刻表、以北京时间计算，并叠加中国官方工作日历。

如果 DeepSeek 以后调整高峰时段，我们会发布包含新时段的新版本——发现不一致欢迎在仓库提 Issue。

## 经济模式（每个对话独立）

会话头部胶囊里现在带一个**绿叶开关**：点开详情卡，底部多出一行「经济模式」，可以为**当前对话**单独开启。

开启后：

- **高峰期自动暂停**——这个对话的模型请求在到达 provider 之前就被挂起（`llm/stream` 是每个模型调用必经的 waterfall），**不发送、不计费**；该对话正在跑的 goal 同时被冻结，状态显示为暂停而不是永远转圈。
- **高峰期间发的消息等空闲再处理**——消息会进对话，但背后的模型调用一直等到谷价时段才开始。
- **空闲期自动恢复**——窗口结束自动继续；重启 dsh 也不会让某个对话永久冻住（冻结记录落盘，新进程只恢复它自己冻的那些）。
- **挂起时显示绿叶休眠条**——composer 上方出现「🍃 经济模式休眠中 · 高峰时段已暂停本对话的模型请求，不会产生费用 · 12:02 自动继续（剩 01:23:45）」。想立刻继续，就在胶囊里关掉这个对话的经济模式。

没有开启经济模式的对话完全不受影响——A 对话可以休眠，B 对话照常全速跑。

时段口径与胶囊显示完全一致（同一份日历、同一套规则），不会出现「胶囊说谷价、闸门还在挂请求」。高峰开始时正在飞的那一个调用会跑完，暂停落在下一步——中途 abort 会把那一步的活儿丢掉。

配置可选，写在 `~/.dsh/profiles/<profile>/cordis.patch.yml` 的 `dsh-peak-status` 行：

```yaml
config:
  economy:
    enabled: true              # 总开关；真正的控制权在每个对话的开关
    windows:                   # 半开区间 [pauseAt, resumeAt)，北京时间
      - { id: peak-am, pauseAt: '09:00', resumeAt: '12:00' }
      - { id: peak-pm, pauseAt: '14:00', resumeAt: '18:00' }
    activeDays: [1, 2, 3, 4, 5]  # 窗口适用的 ISO 星期（周末本就是谷价）
    warnMinutes: 5             # 距高峰多久开始提示
    routeFilter: deepseek-official   # 或 `all`，把所有 provider 都纳管
    defaultEnabled: false      # true = 每个新对话默认开启经济模式
```

状态文件：`$DSH_HOME/peak-status-economy-sessions.json`（每个对话的开关）、`$DSH_HOME/peak-status-economy-paused.json`（本插件冻结的 goal，供重启恢复）。

已知边界：**子代理不随父对话暂停**——它有自己的 session id 和开关；辅助调用（生成标题、compaction）带同一个 session id，会一起挂起。

## 节假日表

节假日表（法定节假日 + 调休上班日）通过网络获取，共三层降级：

1. **host 同源路由** —— 插件 host 半提供 `/dsh-peak-status/holiday/<year>`。它先取 jiejiariapi、失败再取 apihubs，归一化两种返回结构并在内存缓存 6 小时，所有浏览器标签页共用一次拉取。
2. **浏览器直连兜底** —— 路由不可用时，浏览器半改直连 `api.apihubs.cn`（该源允许跨域）。
3. **纯周末规则** —— 完全拿不到日历时，胶囊行为与 1.0.3 完全一致：工作日窗口 + 周末全谷价。

归一化后的结果还会写入 `localStorage` 缓存 24 小时，所以重启或短暂断网时状态依旧正确；详情卡始终标注数据来源（`已同步 · jiejiariapi` / `未同步 · 暂按周末规则`）。

计费口径按 DeepSeek 峰谷时间说明：**调休上班的周末、中国法定节假日全天均按空闲时段计费**。日历提供的就是这两个标注——调休不会带来高峰窗口。
